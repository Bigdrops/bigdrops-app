# 2026-11-18 — Bolu Persistence Integrity Remediation

## Work Completed

Implemented D1, D2, D4 fixes and D3 investigation for the Bolu persistence
integrity audit.

### D1 (Invoice replay lookup type mismatch)
- `findPersistedOperation` changed from `.filter('custom_fields->>operation_id')` to `.eq('operation_id', opId)`
- Root cause: `invoices.custom_fields` is `text`, not `jsonb` — `->>` operator fails silently

### D2 (Database-enforced operation_id uniqueness)
- New migration: `supabase/migrations/20261118120000_bolu_operation_idempotency.sql`
- Adds `operation_id text` column + partial unique index (`WHERE operation_id IS NOT NULL`) to invoices & quotations in all tenant schemas + template
- Backfills from `custom_fields` (invoices: `::jsonb` cast; quotations: direct `->>`)
- Reinstalls save RPCs with `operation_id` in INSERT column list
- App code: `operation_id` in payload; 23505 on `operation_id` treated as replay (re-reads existing document)

### D4 (Fail-safe tenant prefix resolution)
- New `PrefixFetchResult` discriminated union with `status: 'ok' | 'error'` (string literal, not boolean — needed because tsconfig has `strict: false`)
- New `fetchDocumentPrefixesSafe` function in `src/domain/documentNumbering.ts`
- Bolu invoice/quotation paths abort on prefix read failure instead of silently falling back to INV/QTN
- Known gap: manual save hooks (`useInvoiceSave`, `useQuotationSave`) still use React state prefixes — out of scope

### D3 (Investigation only)
- Public-scoped vs tenant-scoped `record_invoice_created` search_path ambiguity
- Callers pass 4 args (no `p_entity_id`); public version falls back to `public.invoices`
- Suspected but unresolved — requires hosted environment to confirm

## Key Technical Decisions
- Chose dedicated `operation_id` column over expression index (avoids text/jsonb mismatch)
- Used string-literal discriminant (`status`) instead of boolean (`ok`) because `strict: false` widens boolean literals
- Kept deprecated `fetchDocumentPrefixes` for non-critical callers (cursor advance path)
