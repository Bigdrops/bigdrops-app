## Changes Made

### 1. Assistant Identity: Bolu Only
- In `assistant-chat-chrome.tsx`, removed the standalone `B` box badge, the `BOUXRE` pill, and the desktop subtitle text.
- The visible header brand displays strictly "Bolu".
- History rail toggle, document panel toggle, More menu, and close action remain fully functional.

### 2. Active Model Picker: Above Composer (Gemini Pattern)
- Relocated the model picker out of the More menu.
- Added `modelPicker` node inside `assistant-chat-composer.tsx` directly above the input textarea.
- The model picker remains visible in the main conversation interface on Mobile, Fold-closed, Fold-open, Tablet, and Desktop viewports.
- In `assistant-chat-model-pill.tsx`, configured upward opening direction (`bottom-full mb-2`) with `max-h-[min(460px,55vh)]` so the model discovery dialog never collides with keyboards, input boxes, or mobile safe areas.

### 3. Direct AI Infrastructure Navigation
- In `BoluChatWorkspace.tsx`, updated `handleNavigateToSettings` to navigate to `/settings?section=bolu-provider`.
- In `Settings.tsx`, integrated `useSearchParams` to inspect `?section=` and automatically activate `bolu-provider` upon mount and parameter changes.
- Selecting "AI Provider Settings" in the More menu now opens the AI Infrastructure view in one user action without displaying the intermediate settings menu.

### 4. AI Infrastructure Mobile Responsiveness
- Root cause identified: `ConnectionCard.tsx` header row applied `shrink-0` to the badge container alongside logo and provider title, forcing cards beyond 100vw on screens <= 390px.
- Removed `shrink-0` from the badge container, allowing `Primary`, `Pool P*`, and `Health` badges to wrap cleanly on narrow screens.
- Added responsive stacking to `BoluProviderSettingsSection.tsx` header actions.
- Grouped card footer buttons into wrapping flex rows with touch-friendly spacing.
- Added flex wrapping to `ModelsManagerSection.tsx` action bar and `AiUsagePanel.tsx` telemetry rows.

### 5. Documentation Synchronization
- Updated `functional-req.md` with requirements FR-43 through FR-46.
- Updated `Waterfall-roadmap.md` with milestone Section 19 detailing implementation and verification.
