# Bolu 2.0 Single Compact Header Row Integration Report

This report was written by Antigravity on 2026-11-16 via Antigravity Agent.

## Objective

Merge the Bolu assistant identity and active model picker into one compact horizontal header row across all four supported viewports (`fold-closed`, `fold-open`, `tablet`, `desktop`). Remove the redundant second vertical model-picker container to conserve vertical screen space. Synchronize the governing Functional Requirements document and Waterfall Roadmap.

## Scope

- Combine the Bolu identity (left) and the active model picker (right) into a single horizontal row within `src/components/ai-assistant/chat/assistant-chat-chrome.tsx`.
- Pass the active model pill (`modelPillNode`) directly to `AssistantHeader` in `src/components/ai-assistant/chat/BoluChatWorkspace.tsx`.
- Completely delete the standalone `modelPickerBar` container.
- Establish the strict three-level vertical workspace hierarchy:
  1. Compact combined Bolu identity and active model header (`headerNode`).
  2. Conversation area / welcome screen / message stream (`threadNode`).
  3. Message composer pinned at the bottom (`composerNode`).
- Bound the model picker width and truncate model identifiers gracefully (`truncate`, `max-w-[130px] sm:max-w-[240px]`) to prevent pushing Bolu off-screen on narrow mobile screens (down to 320 px).
- Set dropdown dialog positioning to right-aligned (`align="right"` / `right-0`) and downward-opening (`direction="down"` / `top-full mt-2`).
- Preserve all existing header controls: conversation history toggle, document panel toggle, More menu, and close action.
- Synchronize requirement FR-44 in `docs/prd/conversational-document-assistant/functional-req.md`.
- Synchronize Section 19.2 in `docs/prd/conversational-document-assistant/Waterfall-roadmap.md`.
- Verify type safety with `bun run typecheck`.

## Changes Made

1. **Merged Model Picker into Single Header Row:**
   - Modified `AssistantHeader` in `src/components/ai-assistant/chat/assistant-chat-chrome.tsx` to render `{modelPill}` inline inside the right-aligned controls group.
   - Preserved left alignment for the conversation history toggle button and "Bolu" title.
   - Preserved right alignment for the active model picker alongside the document panel toggle, More action menu, and close button.

2. **Removed Standalone Model Bar in Workspace:**
   - In `src/components/ai-assistant/chat/BoluChatWorkspace.tsx`, constructed `modelPillNode` with live connection status, active model identifier, downward opening, and direct Settings navigation handler.
   - Passed `modelPill={modelPillNode}` to `AssistantHeader`.
   - Removed the separate `modelPickerBar` container and deleted its JSX references across all four responsive viewports (`fold-closed`, `fold-open`, `tablet`, `desktop`).
   - The workspace layout now transitions directly from the single header row to the message thread, followed by the bottom-pinned composer.

3. **Configured Dropdown Alignment and Responsive Width Bounding:**
   - Added `align?: 'left' | 'right'` property (defaulting to `'right'`) in `src/components/ai-assistant/chat/assistant-chat-model-pill.tsx`.
   - Anchored the dropdown dialog to `right-0` so it expands inward into the conversation space without overflowing off the right edge of the screen.
   - Applied bounded width limits (`max-w-[130px] xs:max-w-[170px] sm:max-w-[240px]`) and `truncate` classes on provider and model labels to prevent pushing Bolu off-screen on 320 px–360 px viewports.
   - Adjusted `.ac-model-trigger` CSS padding to `3px 8px` with `min-height: 32px` in `src/components/ai-assistant/chat/assistant-chat.css` for compact header integration.

4. **Synchronized Functional Requirements (PRD):**
   - Updated requirement FR-44 in `docs/prd/conversational-document-assistant/functional-req.md` to define the unified single-row header architecture with left-aligned Bolu identity and right-aligned active model picker.

5. **Synchronized Waterfall Roadmap:**
