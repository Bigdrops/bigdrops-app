Modals & Sheets (Overlay States)

ActionsSheet: Bottom sheet. Items: Save as Draft, Cancel, Table Columns, Import JSON, Merge Qty+Unit, Add Group, Scroll to Notes, Scroll to Links.
ClientSelector: Bottom sheet with search. Create mode: opens on trigger click. Edit mode: never opens (locked).
ColumnManager: Lazy-loaded sheet. Toggle column visibility, add/remove custom columns, reorder, reset to defaults.
JsonItemsImportSheet: Lazy-loaded sheet. JSON paste/upload → line items.
IdentityLockDialog: Edit mode only. Appears when user clicks locked fields (client, invoice_number). Offers "Duplicate as new document" option.
