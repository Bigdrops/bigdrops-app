## Why This Reference Exists

This repository provides a working implementation of membership-based tenant isolation with Supabase RLS. It explicitly demonstrates USING vs WITH CHECK separation and tests that prove cross-tenant writes fail — exactly the verification BIGDROPS §6 needs.

## Relevant Architecture / Patterns

- **Membership-based isolation**: Users access tenants through a membership join table, not just a `tenant_id` column on user rows.
- **USING vs WITH CHECK** separation demonstrated in practice:
  - `USING (workspace_id = current_setting('app.workspace_id')::uuid)` — gates reads.
  - `WITH CHECK (workspace_id = current_setting('app.workspace_id')::uuid)` — gates writes.
- **All four operations** (SELECT, INSERT, UPDATE, DELETE) have explicit RLS policies.
- **Tests that prove cross-tenant writes fail** — pgTAP-style tests that verify isolation.

## What BIGDROPS Should Borrow

- The **membership-based isolation** pattern — BIGDROPS `workspace_members` + `entity_lifecycle_audit` follow this pattern.
- The USING / WITH CHECK separation in every policy — this is the correct approach for BIGDROPS §6.
- The test approach: pgTAP tests that attempt cross-tenant writes and assert they fail. BIGDROPS should adopt this for §6 verification.
- The explicit policy-per-operation pattern — one policy per (table, operation) for clarity.

## What BIGDROPS Must NOT Adopt

- The single-level tenant model — this repo shows single `workspace_id`; BIGDROPS has workspace + entity (two levels).
- Any SQL patterns that assume direct `psql` access — BIGDROPS uses Supabase migrations.
- The repo may not address `FORCE ROW LEVEL SECURITY` — BIGDROPS must enforce this.

## Known Limitations

- Tutorial-level project; may not address production concerns like connection pooling, policy performance, or edge cases.
- Single-level tenancy — does not address the workspace-entity hierarchy.
- No entity lifecycle (§8A) coverage.

## Bottom Line

The best working reference for USING/WITH CHECK separation on Supabase. The membership-based isolation and cross-tenant test patterns are directly applicable to BIGDROPS §6. Must be extended for two-level tenancy.
