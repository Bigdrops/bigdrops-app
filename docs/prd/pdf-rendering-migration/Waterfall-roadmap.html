    Status:⛔ Pending

  • Step 1.5Implement 5-step rich-text conversion pipeline:

    • Sanitize incoming HTML via DOMPurify with strict allowlist.
    • Parse sanitized HTML into intermediate tree.
    • Map permitted nodes into controlled document AST (<b>, <i>, <u>, <ul>, <ol>, <li>, <p>, <br>).
    • Render AST through Forme components.
    • Fallback unsupported nodes safely to plain text.
    Status:⛔ Pending
Phase 2 Natural Pagination (Normal Mode First) ⛔ Pending ▾
Critical

Gate 1 — Natural pagination on the representative suite first

Verify natural pagination across the complete Representative Document Suite before Phase 3 begins:

  1. Short documents with few line items.
  2. The original 13-item SASQUO-000427 quotation.
  3. Documents with long and wrapping descriptions.
  4. Documents with large totals and bank details.
  5. Documents with notes and commercial terms.
  6. Documents with attachments and signatures.
  7. Multi-page documents with different content distributions.

Compaction must never mask broken natural pagination.

  • Step 2.1Implement Forme Table component with calibrated column widths & oversized row handling:

    • Test candidate target 72 pt for make column (eliminating 2-line wraps for "Atlas Copco").
    • Implement proportional column budgeting for description and item columns.
    • Keep ordinary rows intact across pages where possible; define safe fragmentation or a controlled fallback for rows exceeding available page height, to prevent clipping or silent content loss.
    Status:⛔ Pending

  • Step 2.2Enable native repeating table header (<Row header>) across continuation pages and verify runtime repetition in exported PDF.

    Status:⛔ Pending

  • Step 2.3Implement adaptive closing layout for Bank Details and Totals:

    • Display side-by-side when space and content permit.
    • Provide a deliberate readable fallback (adaptive stacking or continuation) when space is restricted.
    • Avoid rigid row-locking; do not prescribe custom row balancing without measured evidence.
    Status:⛔ Pending

  • Step 2.4Replace defensive global page padding (paddingBottom: 48) with Forme native <Fixed position="footer"> dynamic reservation.

    Status:⛔ Pending

  • Step 2.5Apply selective keep-together behavior:

    • Protect small logical units (individual signature blocks, single table rows).
    • Allow long sections (commercial terms, notes, attachments) to fragment naturally.
    • Mitigate orphaned section headings where practical.
    Status:⛔ Pending

  • Step 2.6Run Gate 1 Verification across the complete Representative Document Suite.

    Status:⛔ Pending
